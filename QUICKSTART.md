# Quick Start Guide

Get DQC running in 5 minutes.

## Step 1: Build Everything

```bash
./gradlew build
```

This does all the setup in one command:
- ✓ Downloads OpenQASM grammar files
- ✓ Generates ANTLR4 parsers
- ✓ Creates Python virtual environment
- ✓ Installs all dependencies

## Step 2: Run the Application

```bash
./gradlew run
```

The GUI will open automatically.

## Step 3: Load an Example

1. Click **File** → **Load Example**
2. Select **QFT** (Quantum Fourier Transform) or **Teleport** (Quantum Teleportation)

The example code will appear in the Source Code tab.

## Step 4: Mark Split Points

Click on lines in the source code to mark where you want to split the program:
- Click on a line number to toggle it as a split point
- The selected line will be highlighted
- You can mark multiple split points to create multiple chunks

## Step 5: View the Analysis

Switch to the **Variable Analysis** tab to see:
- **Variables detected**: All qubit, bit, and classical variables
- **Chunks created**: Which variables are needed for each chunk
- **Dependencies**: What each chunk requires from previous chunks

## Step 6: Save the Chunks

Click **Analyze & Save Chunks** to export:
- Chunks are saved to `split-out/<filename>/`
- Each chunk is a separate `.qasm` file
- Comments show which variables each chunk needs

## Common Workflows

### Analyze a Local File

Instead of loading an example:
1. Click **File** → **Open Local File**
2. Select your `.qasm` file
3. Follow steps 4-6 above

### View the Parse Tree

The **AST View** tab shows the Abstract Syntax Tree generated by the parser. This shows the hierarchical structure of the quantum program.

### Work with Included Files

If your QASM file uses `include` directives:
- The GUI automatically downloads the included files
- Included files appear in separate tabs
- You can view and analyze them separately

## Example: Quantum Teleportation

A classic use case - splitting teleportation into phases:

```
// Full teleportation program
include "stdgates.inc";
qubit[3] q;
bit[3] c;

// Phase 1: Create Bell pair (lines 1-8)
h q[0];
cx q[0], q[1];

// Phase 2: Alice's measurements (lines 9-13)
cx q[0], q[2];
h q[0];
c[0] = measure q[0];
c[1] = measure q[2];

// Phase 3: Bob's corrections (lines 14-end)
if (c[1] == 1) x q[1];
if (c[0] == 1) z q[1];
```

**Workflow:**
1. Load the example: **File** → **Load Example** → **Teleport**
2. Click on line 8 (mark first split point)
3. Click on line 13 (mark second split point)
4. Switch to **Variable Analysis** tab
5. You'll see three chunks with their variable dependencies
6. Click **Analyze & Save Chunks**

**Output files:**
- `split-out/teleport/0.qasm` - Bell pair and variable declarations
- `split-out/teleport/1.qasm` - Alice's operations
- `split-out/teleport/2.qasm` - Bob's corrections

Each chunk includes comments listing the variables it needs.

## Troubleshooting

### "Parser not available"
```bash
./gradlew build
```
Then try again.

### Tkinter not found (Linux)
```bash
sudo apt-get install python3-tk
```
Then run: `./gradlew build`

### GUI doesn't respond
- Close and reopen
- Try a different example file
- Check console output for error messages

### Can't load examples
- Check your internet connection
- Try opening a local file instead
- Manually add `.qasm` files to the project

## Tips

- **Split at natural boundaries**: After quantum operations, before measurements
- **Review variables**: Always check the Variable Analysis tab before exporting
- **Test chunks**: Each exported chunk can be executed independently
- **Use comments**: The analyzer adds comments to exported chunks showing dependencies
